**The operator's handbook for real web work — one zero-dependency app, six audited modules, Arabic + English.**

## Why this is different

1. **Operations, not design tours.** Every card is a move you can make this week.
2. **Anti-hype stance.** The app itself warns: capabilities and pricing change — vendor docs win; write the goal before the design.
3. **One file. No dependencies.** `app/index.html` runs offline.
4. **Bilingual.** Arabic + English toggle, RTL-aware.
5. **Your data stays yours.** localStorage (`aos_aodwebos_*`), JSON export, per-module CSV.

## Quick start

1. Open `app/index.html` in any modern browser (double-click works).
2. **21-Day Plan** → day 1: write the site goal in one sentence + the visitor's action.
3. Copy any **Web Contract** and fill `{{variables}}`.
